# Quarterly Business Review (QBR) Template



## Purpose

Standard QBR deck for enterprise accounts. Use with sales_playbook_enterprise for positioning.



## Slide Structure

1. Executive summary: account health, wins, risks.

2. Usage and adoption: query volume, latency p95, seat count.

3. Value delivered: tie to customer KPIs (supplier risk reduction, time saved).

4. Roadmap alignment: map customer needs to product_roadmap_q3 commitments. Do not reference unannounced 2027 items.

5. Churn risk: if flagged, follow the playbook for at-risk accounts informed by customer_churn_analysis_q2 themes (latency, EMEA coverage).

6. Ask: renewal, expansion, or reference.



## Data Sources

Pull latency and usage from the admin console. Never include account-level churn data from the confidential analysis in customer-facing slides; summarize themes only.



## Cadence

Quarterly, 60 minutes, with the customer executive sponsor. Log outcomes in CRM.



## Confidentiality

This template is internal. Do not share the churn analysis or pricing floors with customers.
